Reading this dashboard

Three things the OpenPages query language decides for you

A count never crosses object types, so each chart reads one type and the number tiles carry the object-wise distribution.

There are no date functions, so trends are plotted per creation date and rolled up for reading rather than grouped by month in the query.

A field an installation does not have drops its chart when the dashboard is built, and the build names what it left out.
